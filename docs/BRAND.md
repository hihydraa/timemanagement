# Dobby — Brand / CI

มาสคอต **Dobby** (เอลฟ์หมวกเขียว) เป็นต้นแบบของ CI ทั้งระบบ ไฟล์ต้นฉบับอยู่ที่รูท repo
(`Waving elf checklist mascot.png`, `Friendly elf productivity sticker set.png`, `Friendly elf productivity sticker trio.png`)

## สี (ดึงจากมาสคอต) — กำหนดใน `apps/web/tailwind.config.js`

| โทเคน                   | ค่า                               | มาจาก           | ใช้กับ                                    |
| ----------------------- | --------------------------------- | --------------- | ----------------------------------------- |
| `brand-500/600/700`     | `#4a7864` / `#3d6552` / `#315243` | หมวก/ผ้าพันคอ   | ปุ่มหลัก, แท็บที่เลือก, ลิงก์, ปุ่มปฏิทิน |
| `slate-50` (ครีม)       | `#fbf7ee`                         | เสื้อ/โน้ต      | พื้นหลังโหมดสว่าง                         |
| `slate-900` (เขียวเข้ม) | `#1c2822`                         | เงาเขียว        | พื้นหลังโหมดมืด / ตัวอักษร                |
| `gold-500`              | `#eea844`                         | กระดิ่ง/ประกาย  | ไฮไลต์ "วันนี้" ในปฏิทิน                  |
| `bark-700`              | `#693d24`                         | รองเท้า/กระเป๋า | สำรองสำหรับกราฟิก                         |

หมายเหตุ: สเกล `slate` ถูก override เป็นเทาอุ่นโทนเขียว ทำให้ทั้งแอปเปลี่ยนโทนพร้อมกัน; สีความเร่งด่วน (แดง/ส้ม/เหลือง/เทา) และสีประเภทงานคงเดิมเพราะเป็นความหมายเชิงข้อมูล (ไม่พึ่งสีอย่างเดียว: มีแถบ + `!` + ★)

## มาสคอตและท่าทาง (`apps/web/public/mascot/*.webp`, PNG สำหรับ LINE)

| ท่า        | ใช้ที่                                                                 |
| ---------- | ---------------------------------------------------------------------- |
| `hero`     | หน้า Login                                                             |
| `morning`  | กำลังโหลด, หัวข้อโฟกัสตอนยังไม่เริ่ม, การ์ดสรุปเช้าใน LINE, `/วันนี้`  |
| `idea`     | Inbox ว่าง, หน้าแอปล่ม (ErrorBoundary)                                 |
| `plan`     | โฟกัสระหว่างจับเวลา, สถิติยังไม่มีข้อมูล                               |
| `deadline` | งานเลยกำหนด (หน้าวันนี้ + LINE)                                        |
| `done`     | ป๊อปอัปฉลองเมื่อทำงานเสร็จ, รีวิวสัปดาห์ที่มีงานเสร็จ, สรุปเย็นใน LINE |
| `rest`     | วันนี้ไม่มีงาน, ช่วงพักโฟกัส, ออฟไลน์, สรุปเย็นที่ไม่มีงานเสร็จ        |
| `hello`    | (สำรอง) ใช้ในภาพ Rich Menu                                             |

คอมโพเนนต์: `Mascot`, `EmptyState`, `CelebrateToast` (`apps/web/src/components/`) ข้อความมาสคอตอยู่ใน `i18n.ts` หมวด `mascot`

## อื่น ๆ

- ไอคอนแอป/favicon/PWA สร้างจากหน้ามาสคอตบนพื้นครีม (`public/icons/`), `theme_color` = `#3d6552`
- Rich Menu: `scripts/richmenu.png` (2500×843) สีเขียว/ครีมตามแบรนด์
- LINE Flex: การ์ดสรุปเช้า/เลยกำหนด/สรุปเย็นมีภาพมาสคอตบนหัว เฉพาะเมื่อ `APP_BASE_URL` เป็น https (LINE ดึงภาพจาก `/mascot/*.png`)
- ชุดท่าที่ยังไม่ได้วาด ที่ต่อยอดได้: เตือนใกล้เดดไลน์แบบเร่งด่วน, Streak, ตอนเลื่อนงาน, ตอนซิงก์ Google สำเร็จ
