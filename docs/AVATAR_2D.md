# ตัวละคร 2D แบบชั้นภาพ — ใช้ภาพของคุณ (art/) และวิธีเพิ่มภาพใหม่

ระบบ: `src/lib/avatar2d.ts` (ตัวประกอบ SVG ใช้ร่วมกันเว็บ/เซิร์ฟเวอร์), `src/lib/avatar2dItems.ts` (รายการไอเท็ม **สร้างอัตโนมัติ**),
API `/api/avatar2d*`, หน้าเว็บ `apps/web/src/pages/AvatarPage.tsx`, สคริปต์เตรียมภาพ `scripts/avatar2d/`.

## ภาพมาจากไหน

`art/Hair/split/<แบบ>/<แบบ>_0_front.png` (ทรงผม 30 แบบ) และ `art/dress/split/<ชุด>/<ชุด>_0_front.png` (ชุด 15 แบบ) — ภาพต้นฉบับเป็น **ตัวละครเต็มตัวพื้นหลังขาว ชิ้นละหนึ่งอย่าง**
(ผม = ตัวละครใส่ชุดรัดรูป+ผมนั้น, ชุด = ตัวละครหัวล้านใส่ชุดนั้น) ไม่ใช่ชั้นโปร่งใส จึงต้องแปลงก่อนใช้:

1. ตัดพื้นหลังขาว (ส่วนขาวที่ต่อกับขอบภาพ)
2. หาตำแหน่งดวงตา แล้วย้าย/ย่อขยายทุกภาพให้ตาอยู่ที่เดียวกัน (ภาพต้นฉบับแต่ละภาพหัวเหลื่อมกัน 20–30 px จึงซ้อนตรง ๆ ไม่ได้)
3. **ชุด** = ภาพทั้งตัวที่ตัดพื้นหลัง (ชั้นล่าง) · **ทรงผม** = สกัดเฉพาะพิกเซลสีเทาอมน้ำตาล (ความอิ่มสีต่ำกว่าผิว/ตา) ที่ต่อกับผมบนศีรษะ (ชั้นบน)
4. สีผมเปลี่ยนด้วยฟิลเตอร์ SVG (ภาพผมเป็นสีเดียว) — ไม่ต้องมีไฟล์ต่อสี

รัน `python3 scripts/avatar2d/export.py` (ต้องมี `numpy pillow scipy opencv-python-headless`) → ได้ `apps/web/public/avatar2d/{hair,outfit}/*.webp` (400×490, ~470 KB รวม) และ `src/lib/avatar2dItems.ts`
ชื่อไทย/ราคา/กลุ่มของแต่ละแบบแก้ที่ตาราง `HAIR` / `OUTFIT` ในสคริปต์ แล้วรันซ้ำ (รหัสไอเท็ม `a-hair-f-bob` … อย่าเปลี่ยนหลังมีผู้ซื้อ)

## ที่ยังไม่ได้ใช้ และเหตุผล

- **ทรงผมยาวที่ทอดอยู่หลังตัว** (`f_long_straight`, `f_long_wavy`, `f_twin_tails`, `f_braided_pigtails`, `n_low_ponytail`): ผมส่วนที่อยู่หลังไหล่/แขนมีสีใกล้เคียงชุดรัดรูปมาก แยกอัตโนมัติไม่ได้ (ลอง GrabCut แล้วไม่ผ่าน)
  และ `n_asymmetric_bob` (ตาซ้ายถูกผมบัง จัดตำแหน่งไม่ได้). ถ้าต้องการ: ส่งภาพ "ผมอย่างเดียว" โปร่งใสของแบบเหล่านี้ (หรือผมสั้นกว่านี้บนตัวละครล้านเปล่า) มาเพิ่ม
- **หมวกแม่มด** (`h_witch_hat`): ภาพหมวกเดี่ยวบนพื้นดำ ไม่ใช่ตัวละคร
- **มุมซ้าย/หลัง/ขวา**: ใช้เฉพาะมุมหน้า (ภาพ 4 มุมมีครบในโฟลเดอร์ ขยายได้ด้วยวิธีเดียวกัน แต่ต้องตรวจตา/สีผมของแต่ละมุม)
- ทรงผมที่เพิ่มบนชุดฐานเดียวกัน หัวของภาพผมบางแบบ (โดยเฉพาะผมหยิก/เอลฟ์) เล็กกว่าหัวบนภาพชุดเล็กน้อย จึงอาจเห็นหนังศีรษะโผล่เล็กน้อย
- สีผิว: ภาพมีสีผิวเดียว จึงไม่มีตัวเลือกสีผิว

## เพิ่มภาพใหม่

- ภาพเต็มตัวแบบเดิม (ผม/ชุด): วางใน `art/Hair/split/<ชื่อ>/` หรือ `art/dress/split/<ชื่อ>/` แล้วเติมแถวใน `HAIR`/`OUTFIT` ของ `export.py`
- ถ้ามีชั้นโปร่งใสพร้อมใช้อยู่แล้ว (canvas เดียวกัน 400×490, ตาที่ตำแหน่งมาตรฐานใน `common.py`) วางตรงที่ `apps/web/public/avatar2d/` ได้เลย แล้วเติมแถวใน `avatar2dItems.ts` (หรือปรับสคริปต์ให้ข้ามขั้นสกัด)
- รัน `npm run test` (ตรวจว่าไฟล์ภาพของทุกไอเท็มมีอยู่จริง) แล้ว deploy — ไม่ต้อง migrate
