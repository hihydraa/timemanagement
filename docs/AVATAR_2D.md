# ตัวละคร 2D แบบชั้นภาพ — วิธีเพิ่มภาพ/ไอเท็มของคุณเอง

ระบบอยู่ที่ `src/lib/avatar2d.ts` (แคตาล็อก + ตัวประกอบ SVG ใช้ร่วมกันเว็บ/เซิร์ฟเวอร์), API `/api/avatar2d*`, หน้าเว็บ `apps/web/src/pages/AvatarPage.tsx`.
ตอนนี้ภาพทุกชิ้นเป็นเวกเตอร์ที่วาดไว้เป็นชุดเริ่มต้น (placeholder) — เปลี่ยนเป็นภาพของคุณได้ทีละชิ้น

## กติกาของภาพ (PNG/WebP/SVG)
- **canvas เท่ากันทุกชั้น 300 × 420 px** (หรือขนาดอัตราส่วน 5:7 เท่ากันทุกไฟล์ เช่น 600 × 840) พื้นหลังโปร่งใส
- ชิ้นส่วนต้องวาง **ตำแหน่งสุดท้ายบน canvas แล้ว** (เหมือนชั้นของโปรแกรมวาดรูป) ระบบแค่ซ้อนตามลำดับ ไม่คำนวณตำแหน่ง
- ลำดับซ้อน (ล่าง→บน): ผมด้านหลัง → ตัว → รองเท้า → กางเกง/กระโปรง → เสื้อ (หรือชุดเต็มตัวแทนสองช่องนั้น) → ของที่คอ → ผมด้านหน้า → แว่น → หมวก → ของถือ → สัตว์เลี้ยง
- ผมที่มีส่วนอยู่หลังตัว (ผมยาว/หางม้า) แยกเป็น 2 ไฟล์: `file` (ด้านหน้า) และ `back` (ด้านหลัง)
- ชื่อไฟล์ใช้ตัวอักษร a-z 0-9 _ - / เท่านั้น นามสกุล png/webp/svg

## ขั้นตอนเพิ่มไอเท็ม
1. วางไฟล์ใน `apps/web/public/avatar2d/` เช่น `hair/wave.png`, `hair/wave-back.png`
2. เติมแถวใน `AVATAR_ITEMS` (`src/lib/avatar2d.ts`):
   ```ts
   { id: 'a-hair-wave', slot: 'hair', th: 'ผมลอนยาว', price: 60,
     art: { kind: 'image', file: 'hair/wave.png', back: 'hair/wave-back.png' } },
   ```
   - `id` ขึ้นต้น `a-` ไม่ซ้ำ; `slot` = hair | top | bottom | outfit | shoes | hat | glasses | neck | hand | companion
   - `price` = แต้ม (0 = ฟรีทุกคน); ไอเท็มใหม่ต้องมีรหัสถาวร (อย่าเปลี่ยน id ที่ผู้ใช้ซื้อไปแล้ว)
3. รัน `npm run test` (ตรวจว่าไอเท็มครบ/ช่องถูก) แล้ว deploy — ไม่ต้อง migrate
4. สีผม/สีผิวใช้ได้กับภาพเวกเตอร์เท่านั้น; ภาพของคุณมีสีในตัว ถ้าอยากได้ผมหลายสี ให้ทำเป็นหลายไอเท็ม

## ของเดิมที่ยังอยู่
ไอเท็มชุดสะสม 6 ตัวละครเดิม (`harry-01` …) และตาราง `game_*` ยังอยู่ครบ ผู้ใช้ที่เคยซื้อไม่เสียของ แต่ UI ใหม่ไม่แสดง
